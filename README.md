# NothingOS Tweaks

Объединённая ветка `nothingos-tweaks`: существующие доработки `icons` и новое контекстное меню из `text-selection-menu`.

## Состав ветки
- Раздельные лимиты значков уведомлений: `X,Y`, например `7,10` — 7 в строке состояния и 10 на AOD. Одно число применяется к обоим; пустое поле оставляет системное поведение. Допустимый диапазон каждого числа: 1–50.
- Расширение области значков и привязка точки переполнения из `icons`.
- Исправления цвета плиток быстрых настроек (QS) из `icons`.
- Настраиваемое текстовое меню: порядок, скрытие действий, короткие подписи, размер текста и положение.
- Автокопирование при выделении полностью отключено; явная команда «Копировать» работает как обычно.
- Остальные твики NothingTweaks и существующий workflow сборки сохранены.

## Основа объединения
- `icons`: `f0ff28840650253df53fb22aecd73c7fe26daba9`.
- Текстовое меню: `77e02873a7005f2ce33bdd9040ab963493f9721f`, до экспериментальных исправлений лимита из `8277a7e`, `d3a42cf`, `03713c9`.
- В объединённой версии не используется однозначный парсер, отвергавший `7,10`, и нет добавленного им ограничения клавиатуры только одним числом.

Сборка: запустить существующий workflow **Build and Release NothingTweaks**, выбрав ветку `nothingos-tweaks`. Unit tests: `bash gradlew :app:testDebugUnitTest`.

## Значки уведомлений — существующее поведение


**Что это?**
Xposed-модуль (форк NothingTweaks) для устройства Nothing на Android 14+ (SystemUI). Управляет тем, как в статус-баре слева отображаются иконки уведомлений.

**Зачем?**
У пользователя часы перенесены вправо (через Iconify), и левая зона освободилась под иконки приложений. Стоковый SystemUI жёстко показывал мало иконок (4 + точка), а точка переполнения стояла с большим зазором относительно ближайшей иконки слева. Задача — отдать левую зону под иконки, задать их число настройкой и красиво прижать точку.

**Что умеет в итоге?**
- Число иконок задаётся пользователем — отдельно для статус-бара и для AOD.
- Если уведомлений не больше лимита — показываются все, без точки.
- Если уведомлений больше лимита — показывается ровно N иконок и точка переполнения вплотную за последней иконкой (никогда не «N+1» иконок).
- То же правило «ровно N иконок + точка» действует и на AOD/локскрине (число берётся из второго параметра настройки).
- Точка держится на месте при анимациях перемешивания, гашении/включении экрана и перезапуске SystemUI.
- AOD/локскрин центрируют иконки как в стоке (мод их раскладку не ломает).

**Настройка.**
Раздел «Status bar» → «Notification Icon Limit». Значение вводится в формате `X,Y`, где `X` — лимит иконок в статус-баре, `Y` — на AOD (например, `7,6`). Если задано одно число — оно применяется к обоим. Пустое поле — стоковое поведение. Подсказка с форматом продублирована в заголовке всплывающего окна ввода.

**Границы.**
Мод не меняет сами иконки приложений, не трогает полку уведомлений (shelf) и не управляет часами/системными иконками справа — только контейнер иконок уведомлений статус-бара.
